# Cube Solver (4×4 first)

React + Vite app. Enter your scrambled 4×4 by painting stickers on an unfolded net, then get the
solution as **Learn** (stage-by-stage with formulas) or **Fast** (one merged move list), with a
step-through player.

    npm install     # also patches cubejs for bundling (postinstall)
    npm run dev     # http://localhost:5173
    npm run build   # production build in dist/
    npm test        # solves random scrambles and verifies every result

## How it solves
Reduction method: 1) centres, 2) pair edges, 3) parity fixes (only if needed), 4) finish as a 3×3
(cubejs/Kociemba on the reduced cube). Centre and edge work uses 3-cycle macros
(setup + commutator + undo) generated by `scripts/findCores.mjs` and `scripts/buildMacros.mjs`
into `src/solver/macroTable.js`. Every solution is replayed on a simulated cube before it is shown.

## Layout
- `src/engine/` sticker geometry, moves, notation, validation, 3×3 view
- `src/solver/` solver + worker; `src/components/` UI
- Sizes are generic in `engine/cube.js`; 2×2, 3×3, 5×5, 6×6 are placeholders in the UI for now.

## Parity formulas (verified in simulation)
- OLL parity: `Rw U2 x Rw U2 Rw U2 Rw' U2 Lw U2 Rw' U2 Rw U2 Rw' U2 Rw'`
- PLL parity: `2R2 U2 2R2 Uw2 2R2 Uw2`
